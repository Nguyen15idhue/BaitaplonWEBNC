# Design System — Travela skeleton (F0)

> Chi tiết đầy đủ do FE hoàn thiện ở F1. Skeleton chỉ chốt token để mọi page sau không lệch.
> Đã áp trong `frontend/travela-web/src/index.css`.

- Font: Inter, system-ui fallback.
- Primary: #2563EB. Nền: #F8FAFC. Chữ: #0F172A. Chữ mờ: #64748B. Viền: #E2E8F0.
- Bo góc: 4, 6, 8. Spacing: 4, 8, 12, 16, 24, 32, 48.
- Cấm: gradient, glassmorphism, màu tự chế, bo góc và spacing ngẫu nhiên.
- Component dùng chung (F1): Button, Input, Table, Pagination, Dialog, Toast, Loading, EmptyState, ErrorState, ConfirmDialog, PageHeader.
